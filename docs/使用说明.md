# scrcpy 5.0.1 使用说明

本文档适用于 scrcpy 5.0.1 Windows 64 位版。

## 安装

本仓库只包含启动脚本，不附带 scrcpy 二进制文件。

1. 从 scrcpy 官方 release 下载 `scrcpy-win64-v5.0.1.zip`，解压到一个固定目录，例如 `C:\Tools\scrcpy-win64-v5.0.1`。
2. 将本仓库的 `src/start-scrcpy.bat` 复制到该目录，并重命名为 `启动scrcpy.bat`。
3. 将本仓库的 `src/wifi-discover.ps1` 复制到同一目录。
4. 双击 `启动scrcpy.bat` 运行。

安装后的目录结构应类似：

```text
C:\Tools\scrcpy-win64-v5.0.1\
├─ scrcpy.exe
├─ adb.exe
├─ 启动scrcpy.bat
└─ wifi-discover.ps1
```

安装目录可以自行选择，只要启动脚本、`scrcpy.exe` 和 `adb.exe` 位于同一目录即可。

## 组件版本

- scrcpy 5.0.1
- adb 37.0.1
- SDL 3.4.18
- FFmpeg 9.0.2
- libusb 1.0.30

## 启动

直接双击 `启动scrcpy.bat`。脚本会按以下顺序自动寻找 WiFi 连接：

1. `adb devices` 中已在线的 TCP/IP 设备
2. `adb mdns services` 的无线调试端点（TLS 优先）
3. 已插 USB 时，用 USB 读取手机 WiFi IP 并切到 `adb tcpip`
4. 电脑所在 /24 网段的 5555 端口扫描
5. 都失败则回退 USB

例如手机地址为 `192.168.1.100`、电脑地址为 `192.168.1.10` 时，两者处于同一 /24 网段，脚本可以完成第 4 步扫描。

WiFi 成功时会显示：

```text
[INFO] selected WiFi endpoint: 192.168.1.100:5555   source: existing-tcp
```

通过 mDNS 发现时，端口由系统随机分配，输出形如 `192.168.1.100:<port>`。

## 首次使用条件

- Android 11+：打开“开发者选项 → 无线调试”，首次与电脑配对一次。
- 或先插 USB 并允许调试，脚本可自动执行 `adb tcpip 5555` 切到 WiFi。
- 不插 USB、从未配对、无线调试关闭时，电脑端无法远程打开手机的调试服务；这是 Android 的安全限制。

## 常用覆盖项

```bat
rem 多设备时指定
set SCRCPY_SERIAL=ABCDEF0123456789

rem 调整窗口
set SCRCPY_WIDTH=720
set SCRCPY_HEIGHT=1560

rem 暂时只用 USB，不自动找 WiFi
启动scrcpy.bat --no-wifi
rem 或
set SCRCPY_NO_WIFI=1

rem 自动化调用：出错不等待按键
启动scrcpy.bat --no-pause
```

端口也可以通过环境变量覆盖：

```bat
set SCRCPY_WIFI_PORT=5555
```

硬件解码异常时，可回退软件解码：

```bat
启动scrcpy.bat --hwdec=disabled
```

## 已验证场景

- WiFi 自动发现：复用已有 TCP/IP 设备、mDNS 发现（TLS 优先）、USB 辅助 `adb tcpip`、/24 网段扫描。
- WiFi 不可用时回退 USB 设备选择。
- 无 WiFi、无 USB 时返回 RC=1，并提示无线调试与 `adb pair`。
- D3D11VA 硬件解码。

## 回滚

本项目不修改 scrcpy 官方文件。需要回滚 WiFi 功能时，用升级前的 `启动scrcpy.bat` 备份覆盖当前文件，并删除 `wifi-discover.ps1`，即回到纯 USB 启动。

## 注意

不要单独替换 `SDL3.dll`、`avcodec-*.dll` 等运行库；`scrcpy.exe` 与 DLL 必须同版本成套使用。
